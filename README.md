## ✨ Overview

**Web Dev Explorer** is a sleek, glassmorphism-styled web application that serves as a comprehensive interactive reference for web development. Browse through HTML tags and CSS properties, read detailed explanations, and experiment with live code — all in one stunning interface.

> 🎯 *Built for learners, by a learner — making web development concepts visual and hands-on.*

## 🚀 Getting Started

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/Jeeva1121/Web-Dev-Explorer.git
   ```

2. **Open in browser**
   ```bash
   cd Web-Dev-Explorer
   ```
   Simply open `index.html` in your browser — **no installation or build step needed!**

3. **Or use Live Server**
   
   If you have VS Code, right-click `index.html` → *"Open with Live Server"* for auto-reload on changes.
